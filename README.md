# For Madhu Sir — "You Were One of My Roots"
### Teachers' Day Interactive Tribute Website

A bespoke, editorial, interactive tribute website created for **Madhu Sir**, Intermediate Physics lecturer.

> *"People see the tree. They don't always see the roots. I do."*
>
> *"Thank you, Madhu Sir, for being one of the roots of who I am becoming."*

---

## Key Highlights & Experience

- **15 Bespoke Visual Chapters**: Every single chapter features a unique visual composition (custom SVGs, interactive path milestones, skill constellations, handwritten notebook margin corrections, golden suspension bridge for trust, botanical tree cross-section, Then vs. Now transformations, and personal letters).
- **Light, Warm Editorial Aesthetic**: Built to feel like luxury stationery and a printed literary keepsake (`#FAF6EE` warm ivory paper, rich charcoal ink, gold accents, soft botanical sage, and terracotta).
- **Mobile-First & Touch-Ready**: Optimized for phone screens with swipe gesture support (`Swipe Left` for next, `Swipe Right` for previous), smooth touch targets, and zero horizontal overflow.
- **Keyboard Navigation**: Full support for `ArrowRight`, `ArrowLeft`, and `Spacebar`.
- **Chapter Quick-Jump Menu**: Table of Contents drawer allowing direct navigation to any chapter at any point.
- **Gentle Acoustic Soundscape**: Synthesized via browser-native Web Audio API (gentle harp chimes and soft paper-turn sounds) with an instant mute toggle.
- **Replay from Beginning**: Smoothly loop back to Chapter 1 from the final letter.

## How to Run Locally

### Prerequisites
- Node.js (v18 or newer)
- npm or pnpm or yarn

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Open in your browser
# Visit http://localhost:3000
```

### Production Build
```bash
# Compile TypeScript and bundle assets
npm run build

# Preview production build locally
npm run preview
```

---

## Deploying to Web

You can easily host this website for free on platforms like **Vercel**, **Netlify**, or **GitHub Pages**:
- **Vercel**: Import this project folder or Git repo; framework preset is automatically detected as `Vite`.
- **Netlify**: Drag and drop the `dist/` folder or link repository with build command `npm run build` and publish directory `dist`.
